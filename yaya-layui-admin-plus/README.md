## 介绍
`YaYa-Layui-Admin-Plus`是基于[LayUI](https://layui.dev/)实现的前端管理模板，项目采用原始单页独立的构建方式，不依赖脚手架，开发者只需要掌握简单的HTML/CSS/JS基础知识即可快速上手，开发和维护成本极低。

## 设计初衷

> 🌟 需要一套最简单的技术栈，来降低前端的学习、开发和维护成本。
