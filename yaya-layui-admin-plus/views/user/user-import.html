2填写规则
  • 用户名、昵称、部门ID为必填项，用户名全局唯一。
  • 密码留空时，初始密码为 123456。
  • 手机号、邮箱填写后，不能与其他未删除用户重复。
  • 角色/岗位填写编号，多个用英文逗号分隔。
  • 不允许分配 ROOT 角色。
  • 导入采用整批校验：任意一行有错误，整批都不会导入。
